# 语言接触的四种结果：线性分步版

> `V-OSP` 成对的**线性分步版（B 版）**。与同目录的 `-G.png`（结构图，A 版）信息量相近。

两个变量决定落进哪个格子：接触强度、人口比例。

1. 第一步，定两个变量。横轴是接触强度（交流有多频繁、持续多久）；纵轴是人口比例（说这种语言的人在当地占多数还是少数）。
2. 第二步，接触弱、人口占多数 → 借用：主要借用词汇与个别结构，语法体系基本不动。
3. 第三步，接触强、人口占多数 → 语言转移：外来结构渗入本族语，但本族语仍在使用。
4. 第四步，接触强、人口为少数 → 替换：少数群体在两三代内转向多数语，本族语退出日常使用。
5. 第五步，人口相当且接触强 → 混合：出现混合语或克里奥尔语，语法与词汇各取一部分。
6. 第六步，保留限定：四个格子是倾向，不是判据。同一种接触在不同社区可以落进不同格子，取决于教育、通婚与语言政策。

# redesign · 已接上真后端的界面

这份界面本来是两份静态原型之一（`frontend/quiet/` 是另一份，**没有动过**）。
现在它是**能真的用**的那一份：标记、样式、动画、文案都还是原型的原样，
换掉的只有数据来源 —— 从写死的假数据换成 `http://127.0.0.1:8000` 上那个真后端。

## 怎么起

```powershell
# 在 backend/ 下
$env:MOUXUE_SKIP_ENV_FILE="1"; $env:PYTHONIOENCODING="utf-8"
.\\.venv\\Scripts\\python.exe -m tools.seedui --db var/ui_live.db --reset   # 铺一份能看的演示数据（全部走真 HTTP 端点）
.\\.venv\\Scripts\\python.exe -m tools.serveui --llm fake --db var/ui_live.db --port 8125 `
    --dist ..\\frontend\\redesign --items-dir tests\\fixtures\\bank `
    --script-session S-0001 --frame-delay 0.01
```

打开 <http://127.0.0.1:8125/>。`--llm fake` 是替身模型（不联网、按剧本回），
换成 `--llm` 的真实取值就会走真模型 —— 界面这一侧一行都不用改。

## 文件为什么这么拆

| 文件 | 管什么 | 为什么单独一份 |
| --- | --- | --- |
| `index.html` | 骨架 + 那套内联 SVG 图标 | 原样保留 |
| `styles.css` | 全部样式 | 原样保留（只补了三个工具状态的圆点颜色） |
| `app.js` | 渲染与交互 | 与原型同一套写法，只把数据换成请求 |
| `src/api.js` | **唯一**的出口：HTTP + SSE | 换端口、换错误形状只需要改这一处 |
| `src/adapt.js` | 后端 DTO → 界面要的结构 | 字段名对不上的地方集中在这一处，不在渲染代码里散着 |
| `src/live.js` | 一轮讨论的生命周期 | 时序（stage → token → tool → done / 停止）最容易坏，单独一页说清 |
| `src/selftest.js` | 无头验收的探针（`?probe=1` 才加载） | 验收要像人一样点一遍，不该混进产品代码 |

没有构建步骤、没有 npm、没有框架：`<script type="module">` 直接用。
这是有意的 —— 原型只有一份 HTML 能用浏览器打开，加了构建链就多一层会坏的东西。

## 现在哪些是真的

- **会话流**：发一句话 → 真的 `POST /discuss/stream`，逐帧读 SSE，状态行说"读取会话 / 组织回答 / 调用工具"，
  正文逐字落墨，工具轨迹一行一条，收官后脚注写清"这一轮几个工具动作"。
- **停止**：真 abort，服务端走 `client_disconnected`，不是界面假装停了。
- **工具轨迹的四种状态**：`success` 绿点 / `empty` 绿点（"没有找到"也是做成了）/ `rejected` 金点（被守卫拦下，**改动没发生**）/ `error` 朱点。
- **「为什么这样建议」**：按这一轮真的发生过什么生成，不是一句写死的套话。
- **计划**：点圆圈真的 `PATCH /plan/steps/{id}`；点整行 = 把这一步当成讨论锚点（占位文案会变成"关于第 N 步…"），
  有锚点之后「起草计划改动」才被允许写库 —— 没有锚点时守卫会拒绝，界面就照实显示"被拦下"。
- **状态胶囊**：顶栏那颗胶囊可以点，按后端的转移边表给出"下一步"（`draft` → 开始执行、
  `active` → 结束执行 / 完成、`review` → 回到执行 / 完成、`completed` → 重新打开）。
  点之前先 `GET /state` 现读版本号，所以不会拿旧版本去换一发 409；失败把后端原话 toast 出来。
  归档（`completed`）之后仍能发消息、记笔记，但改定义区与改计划会被拒 —— 那之后改，
  「当时为什么这么总结」就核对不了了。
- **侧记**：真的 `POST /notes`，回执里带后端给的笔记编号。
- **侧栏**：新建 / 改名 / 归档 / 恢复 / 删除 会话，全部走真端点；归档是时间戳，不是状态。
- **上下文**：`done` 事件里的计量才是真的。`/state` 里没有计量，所以刷新页面后显示"没测到" —— 那时候确实不知道。

## 哪些还是占位（点得出来，但没有假装成功）

`标注一句`、`编辑动机·版本历史`、`基准测试`、`设置里的模型管理`、语言切换（英文文案在 i18n 表里，但后端不返回英文）。
它们只给一句实话的提示，不会显示一个假的结果。

## 怎么验

```powershell
# 在仓库根下（服务已起在 8125）
node var_ref/headless_probe.mjs
```

它会开一个真的无头 Edge，点开一个计划项、发一句话、等回答、看轨迹、写一条侧记，
再把一个会话走完"新建 → 改名 → 归档 → 恢复 → 删除"，把每一步的结果打到标准输出。
退出码 0 = 全部通过。

`?probe=1` 才会加载探针（动态 import），正常打开没有任何多余代码。
